# File Organizer System

A Python application that helps organize files into category-based folders. The project scans a selected directory, identifies file types, and moves files into separate folders such as Images, Documents, PDFs, and Videos.

## Features

- Organize files by type
- Create folders automatically
- Move files to matching categories
- Display organization summary
- Multi-module project structure

## Project Structure

The application separates file processing, folder creation, category management, validation, and summary generation into different modules to keep the code organized and easy to maintain.
